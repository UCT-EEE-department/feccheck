UCT EEE Staff Academic Advisor

Federated launcher for staffadvisor — works with ChatGPT, Claude, Gemini, Antigravity, and Claude Code.

Option 1: Web Chat (ChatGPT, Claude, Gemini — no install)

Copy the latest Staff Advisor system prompt directly from UCT-EEE-department/feccheck and start a session in your preferred AI tool:

View Raw Prompt

ChatGPT

Paste into a new chat (or a Custom GPT's Instructions), then paste the anonymised course record.

Claude

Paste into a new chat (or a Claude Project's Instructions) and optionally attach the reference files below.

Gemini

Paste into a new chat (or a Custom Gem's Instructions), then enter the student's course history.

Optional Reference Manuals (for uploading as Project / Custom GPT / Gem knowledge):

  • Curriculum & Equivalencies
  • Progression Rules, Honours & Cycle Stages
  • 2026 Timetable Grids & Clash Rules
  • Standardised Staff Advising Report Template
POPIA Reminder: Never paste student names, Campus IDs, or raw CRS CSV files into consumer web chats. Strip identifying headers or use an anonymised record before uploading.

Option 2: Local Agentic Setup (Antigravity / Claude Code / Codex)

Runs the deterministic feccheck Python engine (advise_student.py) locally on your machine—zero hallucinations on credit totals, equivalencies, or timetable clashes, and student data never leaves your computer.

git clone https://github.com/UCT-EEE-department/feccheck.git
cd feccheck
pip install -r requirements.txt

Open the cloned folder in Antigravity (.agents/skills/) or Claude Code (.claude/skills/) and invoke /staffadvisor.
